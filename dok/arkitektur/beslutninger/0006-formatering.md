# 6. formatering

Date: 2021-01-01

## Status

Akseptert

## Kontekst

Vi ønsker å slippe å bruke tid på formatering, både ved utvikling og ved review av andre sine pull requests.

## Beslutning

Vi beslutter å bruke [prettier](https://github.com/prettier/prettier) i prosjektet. Prettier wil kjøres ved hver commit, bare på den koden som har endret seg.

## Konsekvenser

Utviklere vil ikke lenger trenge å formatere kode selv.
