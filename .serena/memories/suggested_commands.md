# Suggested Commands

- Install deps: `pnpm install`
- Start dev: `pnpm start`
- Start with env: `pnpm start:q1` / `pnpm start:q2`
- Preview build: `pnpm serve`
- Build: `pnpm build`
- Unit tests: `pnpm test` (coverage: `pnpm test:coverage`)
- E2E tests: `pnpm test:e2e` (UI: `pnpm test:e2e:ui`)
- Lint: `pnpm eslint`
- Format: `pnpm prettier:check` / `pnpm prettier:write`
- GraphQL codegen: `pnpm generate-graphql`
